# 🌶️ ChilliCrop Analytics Dashboard

An interactive, single-page analytics dashboard for chilli crop monitoring —
yield analysis, weather impact, pest tracking, and market prices across major
Indian chilli-growing regions (Guntur, Byadgi, Warangal, etc.).

## ✨ Features
- 📊 **Overview Dashboard** — KPIs, yield/price/pest charts, live alerts
- 📈 **Yield Analysis** — variety & region comparisons, growth-stage timeline
- 🌦️ **Weather Impact** — temperature/humidity trends, rainfall-vs-yield correlation, 7-day forecast
- 🐛 **Pest Monitor** — risk levels, treatment recommendations, trap zone status
- 💰 **Market Prices** — mandi price trends, export vs domestic split
- 📋 **Reports** — generated report list and quarterly revenue overview
- ⚙️ **Settings** — alerts, language, refresh interval

## 🛠️ Tech Stack
- HTML5 + CSS3 (responsive, mobile-friendly sidebar)
- JavaScript (vanilla)
- [Chart.js](https://www.chartjs.org/) (via CDN)

## 🚀 Run Locally
Just open `index.html` in any browser — no build step or dependencies.
